## Submission description

AgentReady is a no-code WebMCP Builder for Framer. It scans the site designers have already built — pages, links, CMS collections, and forms — and turns those existing structures into explicit, typed tools for AI agents.

Instead of asking every Framer creator to learn JavaScript, JSON Schema, and browser security details, AgentReady presents safe capabilities as switches. The complete runtime covers 30 tools across page and CMS discovery, advanced and multi-step forms, accessible option/date controls, address entry, human-mediated file upload, conversational chat, safe checkout preparation, Shopify Storefront MCP/UCP commerce, Cloudflare Agentic Payments, Pay Per Crawl policy discovery, AI Search knowledge, cited answers, and cryptographic provenance.

When the creator selects Install tools, AgentReady generates an imperative WebMCP runtime and places it in Framer Custom Code. It runs as top-level page JavaScript, requires no separate backend, excludes draft CMS entries, and travels with the normal Framer publishing workflow.

The live demo is itself a responsive Framer site created and edited through a Framer MCP server. The repository includes isolated tests for all 30 browser tools, Hybrid de-duplication, the same-origin MCP gateway, and an end-to-end test for published Custom Code. Shopify's native MCP/UCP endpoints provide catalog, policy, and cart semantics, with GraphQL fallback when a store restricts MCP. Payment boundaries are explicit: AgentReady can assemble a Shopify cart and prepare checkout, while Shopify owns retail payment authentication; Cloudflare's edge-injected WebMCP bridge and Workers demonstrate remote tool composition, agent-native HTTP 402 payment challenges, paid-crawl pricing, AI Search knowledge, anonymous tool analytics, C2PA metadata inspection, and Browser Run readiness verification.

The demo is self-hosting: its main checkout form sells Creator, Studio, and Agency AgentReady licenses using the WebMCP capabilities generated by AgentReady itself. An agent can choose a license, prepare buyer and order details, create a Shopify cart or request a tier-specific Cloudflare MPP challenge, and hand off only credential entry and final confirmation to the buyer.

AgentReady's larger vision is an Agent API Builder for Websites: a visual layer where site owners can design, test, publish, monitor, and improve the actions their websites offer to agents. Framer is the first distribution surface because its structured canvas and CMS make those actions understandable to creators without code.

## Judging points

- WebMCP leverage: real imperative tools registered by top-level page JavaScript.
- Execution: a working Framer plugin, deployed demo, 30 optional browser tools plus an 11-tool edge gateway, runtime/gateway tests, live E2E test, five Cloudflare Workers, and CI.
- Impact: makes WebMCP accessible to a large no-code creator audience.
- Creativity: treats agent capabilities as a visual website-design primitive rather than a developer-only integration.
